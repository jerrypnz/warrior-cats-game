# Sound Effects Library

Place kid-friendly sound effect files here (.wav or .ogg format).

## Recommended Free Sound Packs

Kenney.nl Game Assets (all CC0, completely free):
- Interface Sounds
- Impact Sounds
- Digital Audio

Download from the Kenney website and place the files in this folder.

## Suggested Sound File Names

For Claude to automatically use these sounds, name them:

- `jump.wav` — player jumping
- `land.wav` — player landing
- `collect.wav` — collecting coins/stars/items
- `hurt.wav` — player getting hurt (keep it mild/cartoony!)
- `enemy_bonk.wav` — defeating an enemy
- `win.wav` — level complete / winning jingle
- `lose.wav` — game over sound (keep it lighthearted)
- `click.wav` — menu button click
- `select.wav` — menu selection
- `powerup.wav` — getting a power-up
