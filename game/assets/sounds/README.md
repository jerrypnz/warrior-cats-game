# Sound Effects Library

Kid-friendly retro sound effects for the game to use. The starter set is generated by
`python3 tools/make_sounds.py` — no downloads needed.

- `jump.wav` — player jumping
- `land.wav` — player landing
- `collect.wav` — collecting coins/stars/items
- `hurt.wav` — player getting hurt (mild and cartoony)
- `enemy_bonk.wav` — defeating an enemy
- `win.wav` — level complete / winning jingle
- `lose.wav` — game over (a silly "wah wah wah", not a sad one)
- `click.wav` — menu button click
- `select.wav` — menu selection
- `powerup.wav` — getting a power-up

## Swapping in Other Sounds

Any `.wav` or `.ogg` file with one of these names can replace the generated one (Kenney.nl's
free CC0 "Interface Sounds", "Impact Sounds" and "Digital Audio" packs are a good source).
`make_sounds.py` never overwrites existing files unless run with `--force`.
